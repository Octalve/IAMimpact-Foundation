# IAMimpact production image guide

The website uses stable local placeholders so missing remote images never break
the build. Replace them with approved local files in this directory and use
`next/image`.

Suggested subjects:

- Hero: African secondary-school students collaborating during a digital,
  leadership or climate programme.
- Programmes: students using laptops, youth-led tree planting, facilitators
  working with community groups.
- Impact stories: dignified individual portraits connected to verified
  programme outcomes.
- Community: volunteers and residents designing or delivering a local solution.

Research references (do not copy or hotlink without confirming usage rights):

- UNICEF Nigeria, collaborative e-learning in Lagos:
  https://www.unicef.org/nigeria/stories/thriving-e-learning-how-bolade-transformed-her-biology-scores
- Generation Unlimited, youth climate action:
  https://www.generationunlimited.org/stories/green-rising-powers-tackle-climate-change
- AREAi, Nigerian schoolgirls and digital skills:
  https://areai4africa.org/bridging-the-gender-digital-divide-the-role-of-partnerships-and-grants-in-empowering-girls-with-digital-skills/

Safeguarding:

- Obtain consent before using identifiable participant images.
- Obtain appropriate guardian consent for minors.
- Keep names, school details and location metadata private unless publication is
  explicitly approved.
- Avoid stereotypical or dignity-reducing imagery.
